Five pages, each answering one question

Home is the summary you land on. Work is what your factory is producing. Reviews is other people's code that waits on you. Activity is what already happened, yours and the team's. New starts a chat or a task; attaching a ticket is what turns a task into tracked work.

Rules every screen follows
Humans only at gates. Brainstorm, spec review, high-risk PR review, merge. Everything else runs on its own and escalates when stuck.
Blocking first. A paused run beats a gate beats a review for a teammate beats an FYI.
One primary action per row. The next step is a button; the rest are links.
Facts, not claims. States change on run, PR and Jira facts, never on what the agent says.
Unknown is not zero. Missing data shows “—” with a reason. Cost is always “est.”.
The agent drafts, you post. Reviews, replies and fixes reach other people only after you say yes.
